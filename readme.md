# gnome-screenshort-cut-extension

A simple shortcut button to call the native screenshot tool directly on your GNOME panel.

[Fork changes]

*Centered icon after the date menu.
*Changed the icon.

[![Get it on GNOME Extensions](get-it-on-gnome-extensions.png)](https://extensions.gnome.org/extension/6868/screenshort-cut)

## Packing the extension

```sh
gnome-extensions pack --out-dir=./dst ./src
```
